PARENT APP FRONTEND PACK

This package contains the Parent App frontend route files.

HOW TO APPLY WITHOUT TERMINAL:
1. Extract this ZIP using Ubuntu Files (right-click > Extract Here).
2. Open your existing parent-app project in VS Code.
3. In the extracted folder, open the src folder.
4. Copy the app and components folders.
5. Paste them into your existing parent-app/src folder.
6. If Ubuntu asks whether to merge folders and replace files, choose Merge/Replace.
7. Save all files in VS Code.
8. Reload the running Expo app. If it does not refresh, stop Expo and start it again using your usual project workflow.

IMPORTANT:
- This is a frontend UI demonstration pack.
- Login, registration, forgot-password, device monitoring, remote lock, DNS filtering and other actions are not connected to a backend yet.
- The login screen currently navigates to the dashboard after non-empty email/password input.
- Registration validates fields locally but does not create a real account.
- Do not use real passwords in this demo.
- Keep your existing package.json and node_modules; this package does not replace them.
